# 0.11.0 — 2026-11-10

## Added

- **`brapi-guide`** ships with the server and is discoverable through MCP at `skill://brapi-guide/SKILL.md`. It covers phenotype comparisons, genotype exports, and querying staged dataframes.

## Changed

- **`brapi_dataframe_query` (breaking)** rejects unqualified `current_schema` columns and reserved catalog identifiers such as `pg_class` and `pg_settings`, including when used for ordinary columns, aliases, CTEs, or tables. Qualify `current_schema` with a table alias and rename other rejected identifiers.
- **`brapi_dataframe_query`** supports read-only `DESCRIBE`, `SHOW`, and `SUMMARIZE` statements. SQL rejections expose the specific `data.gateReason`.
- **Runtime** requires Bun 1.4.4 or newer for Bun installations.

## Fixed

- **`brapi_find_locations`** uses dialect-specific GeoJSON axis order consistently across pages and expands CassavaBase country names to ISO alpha-3, alpha-2, and numeric codes. ([#103](https://github.com/cyanheads/brapi-mcp-server/issues/103), [#110](https://github.com/cyanheads/brapi-mcp-server/issues/110))
- **`brapi_find_observations`** honors germplasm scope on SGN and verifies it locally on fallback routes. Applied-filter text preserves nested criteria and completed empty scans suggest broadening. ([#104](https://github.com/cyanheads/brapi-mcp-server/issues/104), [#105](https://github.com/cyanheads/brapi-mcp-server/issues/105))
- **`brapi_find_images` and `brapi_find_variants`** verify named MIME and region filters before previewing, counting, or staging results. Warnings distinguish missing evidence from contradictory rows. ([#116](https://github.com/cyanheads/brapi-mcp-server/issues/116))
- **`brapi_build_phenotype_matrix` and `brapi_germplasm_performance`** default to 50,000 matching observations per study, accept a lower `loadLimit`, and disclose incomplete scans. ([#113](https://github.com/cyanheads/brapi-mcp-server/issues/113))
- **Dataframe staging** shares one canvas across concurrent calls in the same scope, including after the canvas expires. ([#108](https://github.com/cyanheads/brapi-mcp-server/issues/108))
- **Genotype search and export** use consistent asynchronous pagination and preserve scalar calls. Ambiguous numeric scalars remain in the matrix and are marked missing in VCF-lite and PLINK. ([#109](https://github.com/cyanheads/brapi-mcp-server/issues/109))
- **`brapi_export_genotype_matrix`** maps PLINK allele indices to REF/ALT or positive numeric labels and stages a queryable empty table when no calls match. ([#112](https://github.com/cyanheads/brapi-mcp-server/issues/112))
- **Startup configuration** applies DuckDB and dataframe export defaults after loading `.env` on Node and Bun.
