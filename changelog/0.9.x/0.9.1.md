# 0.9.1 — 2026-10-18

## Fixed

- **SGN observation collection** uses advertised embedded observation units for study pulls, retaining zero-valued measurements, child metadata, and caller filters while paging by raw unit totals. Repeated observation IDs are counted once. ([#86](https://github.com/cyanheads/brapi-mcp-server/issues/86))
- **`brapi_germplasm_performance`** walks germplasm-scoped embedded units on SGN servers, avoiding ignored study-discovery filters and the 200-study discovery cap; per-study observation limits and incomplete scans are disclosed. ([#87](https://github.com/cyanheads/brapi-mcp-server/issues/87))
- **Phenotype coverage** distinguishes contributed, empty, failed, partial, and unprocessed studies in structured and formatted output; failed study pulls mark matrix coverage incomplete. ([#89](https://github.com/cyanheads/brapi-mcp-server/issues/89))
- **Distribution rankings** sort numeric-like and mixed keys by descending count before rendering or selecting refinement hints. ([#88](https://github.com/cyanheads/brapi-mcp-server/issues/88))
- **`brapi_get_study`** renders companion object arrays as bounded JSON while preserving scalar-array presentation. ([#90](https://github.com/cyanheads/brapi-mcp-server/issues/90))
- **`brapi_find_locations`** rejects malformed nonempty bounding boxes and wholly unresolved country restrictions; alphabetic codes are uppercased and numeric upstream codes remain usable. ([#94](https://github.com/cyanheads/brapi-mcp-server/issues/94))
- **SGN study programs** lift missing program fields from `additionalInfo` and resolve a parent trial's program when the study lacks an ID, preserving raw study metadata and caller cancellation. ([#96](https://github.com/cyanheads/brapi-mcp-server/issues/96))
