# 0.7.8 — 2026-07-16

## Added

- **`brapi_germplasm_performance` `studyDbIds`** — optional input that bypasses automatic study discovery (and its 200-study `STUDY_DISCOVERY_CAP`) entirely. Pass a specific set — e.g. the full germplasm-scoped list retrieved via `brapi_find_studies` with `extraFilters.germplasmDbIds` — to aggregate a slice discovery would otherwise cap. ([#43](https://github.com/cyanheads/brapi-mcp-server/issues/43))
- **`germplasmDbIds`** — added to the `/studies` filter catalog (`brapi_describe_filters`); the capped-discovery warning on `brapi_germplasm_performance` now names this `brapi_find_studies` retrieval path alongside the `studyDbIds` input above. ([#43](https://github.com/cyanheads/brapi-mcp-server/issues/43))
- **`brapi_walk_pedigree` dataframe spillover** — new `loadLimit` input; when the node or edge set exceeds it, both spill to two canvas dataframes (`nodesDataframe` / `edgesDataframe`, JOINable on `germplasmDbId`) with a bounded inline preview. Completes [#17](https://github.com/cyanheads/brapi-mcp-server/issues/17) — Part B of the walk's cap handling; the 1,000-node safety cap and truncation warning (Part A) shipped in [0.7.1](https://github.com/cyanheads/brapi-mcp-server/blob/main/changelog/0.7.x/0.7.1.md).
- **`brapi_find_locations` `countryNames`** — free-form English country names and aliases (e.g. "Uganda", "USA") resolved client-side to ISO 3166-1 alpha-3 codes and merged into `countryCodes`; unresolved names surface as a warning. New `src/services/iso-country/` service backs the resolution — 249 countries, case- and diacritic-insensitive, accepts alpha-2/alpha-3 codes directly. ([#19](https://github.com/cyanheads/brapi-mcp-server/issues/19))
