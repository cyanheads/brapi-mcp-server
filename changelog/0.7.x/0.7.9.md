# 0.7.9 — 2026-07-16

## Added

- **`brapi_export_genotype_matrix` `maxColumns`** — optional per-call input capping the distinct variant columns the matrix pivots into. Omit to use the deployment ceiling; a value above it clamps down. Independent of `maxCalls`, which bounds the row (call) pull. ([#46](https://github.com/cyanheads/brapi-mcp-server/issues/46))
- **`BRAPI_GENOTYPE_MATRIX_MAX_COLUMNS`** — deployment ceiling on distinct-variant columns per matrix; bounds the wide canvas dataframe, the `variantColumnLegend`, and any VCF/PLINK text, all of which scale with column count independently of `BRAPI_GENOTYPE_CALLS_MAX_PULL`. Default 10,000 (legend ≈ 250 KB), max 500,000. Prevents a schema-legal one-germplasm × many-variant skew from driving the column count to the full call budget and emitting a multi-megabyte legend. ([#46](https://github.com/cyanheads/brapi-mcp-server/issues/46))

## Changed

- **`brapi_export_genotype_matrix` `truncated`** — now set when either cap fires: the row ceiling (`BRAPI_GENOTYPE_CALLS_MAX_PULL`) or the new column ceiling; `warnings` names which. The column cap is applied inside the pivot as rows stream in, so an over-wide legend and matrix are never built then trimmed. Every germplasm still registers as a row — one whose calls all reference dropped variants renders as an all-null row, never a vanished one. ([#46](https://github.com/cyanheads/brapi-mcp-server/issues/46))
- **`brapi_dataframe_describe` per-column listing** — bounded by the shared width-aware budget (`joinWithinBudget` / `MAX_LIST_LINE`, now exported from `find-helpers`), so a wide genotype matrix no longer emits one `content[]` line per variant. Overflow points at `brapi_dataframe_query` (`SELECT * FROM <table> LIMIT 0`); the full schema stays in `structuredContent`. ([#47](https://github.com/cyanheads/brapi-mcp-server/issues/47))
- **`renderDataframeHandle` overflow hint** — repointed from `brapi_dataframe_describe` to `brapi_dataframe_query`, since describe's listing is now itself budgeted and pointing one capped line at another is circular. ([#47](https://github.com/cyanheads/brapi-mcp-server/issues/47))

## Dependencies

- **`tsc-alias` `^1.8.17 → ^1.9.1`** — dev-dependency bump.
