# 0.12.0 — 2026-11-20

## Added

- **`brapi_federated_find`** searches studies, germplasm, or observations across BrAPI aliases, preserving source-local IDs and coverage and staging one merged dataframe when needed. Only unambiguous exact germplasm PUIs group records across aliases. ([#11](https://github.com/cyanheads/brapi-mcp-server/issues/11))

## Changed

- **`brapi_build_phenotype_matrix`** preserves observation and unit IDs and available field design in long rows. Wide cells pool by germplasm and variable across studies and report their contributing counts. ([#106](https://github.com/cyanheads/brapi-mcp-server/issues/106))
- **`brapi_get_image` and `brapi_walk_pedigree`** process the first five distinct image IDs or twenty distinct pedigree roots in input order and return the remainder for another call. Positive pedigree depths above ten use ten. ([#107](https://github.com/cyanheads/brapi-mcp-server/issues/107))
- **`BRAPI_CALL_DEADLINE_MS`** sets the shared upstream deadline, defaulting to 50,000 ms. Embedded observation-unit reads can use the remaining call budget. ([#114](https://github.com/cyanheads/brapi-mcp-server/issues/114))
- **`brapi_submit_observations`** reviews values against declared scales and checks study membership when evidence is available. Preview and apply confirmation report the number of rows flagged by advisory checks. ([#117](https://github.com/cyanheads/brapi-mcp-server/issues/117))
- **`brapi_find_variables`** prioritizes exact PUIs and then exact normalized names in text ranking, ignoring a matching trailing PUI suffix for comparison. ([#118](https://github.com/cyanheads/brapi-mcp-server/issues/118))
- **`brapi_find_germplasm`** accepts study, trial, and program scopes and reports when count evidence cannot confirm narrowing. ([#119](https://github.com/cyanheads/brapi-mcp-server/issues/119))

## Fixed

- **Finders** expand multivalue filters into bounded scalar GET requests when the dialect requires them and POST cannot serve the list. Results are deduplicated by resource ID and disclose incomplete coverage. ([#111](https://github.com/cyanheads/brapi-mcp-server/issues/111))
- **Capability discovery** returns `capability_discovery_not_found` when both discovery endpoints return HTTP 404, with a versioned BrAPI URL suggestion for root URLs. Failed discovery leaves an existing alias registration intact. ([#115](https://github.com/cyanheads/brapi-mcp-server/issues/115))
