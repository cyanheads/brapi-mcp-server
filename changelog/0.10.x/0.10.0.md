# 0.10.0 — 2026-10-18

## Changed

- **`brapi_get_image`** removes `images[].data` from structured output; image bytes are emitted once as MCP image content. Consumers reading structured base64 must read the image content blocks instead. ([#91](https://github.com/cyanheads/brapi-mcp-server/issues/91))

## Fixed

- **Raw and pedigree previews** fit both array JSON and serialized rendered rows within 24,000 bytes, retaining omitted fetched rows in dataframes. Explicit raw paging stages only the requested upstream page; async search forwards its page parameters. ([#76](https://github.com/cyanheads/brapi-mcp-server/issues/76))
- **`brapi_dataframe_query`** bounds wide rows while preserving full `registerAs` materialization, typed columns, actual `shown`, and the effective row `cap`. Ordered pages advance by delivered rows; zero-row previews require a narrower projection or aggregation. ([#92](https://github.com/cyanheads/brapi-mcp-server/issues/92))
- **`brapi_walk_pedigree`** separates confirmed leaves from unresolved directions, marks safety-capped graph coverage partial, and stages fetched omitted relatives with ordinal ordering for ID retrieval. Diagrams describe only the discovered graph. ([#93](https://github.com/cyanheads/brapi-mcp-server/issues/93))
- **Image MIME validation** rejects non-image responses per ID from either byte source, normalizes case and parameters, and uses metadata when response MIME is absent; successful siblings remain available.
- **Caller guidance** names deployment ceilings without operator environment variables and qualifies optional dataframe removal while offering a different `registerAs` name. ([#99](https://github.com/cyanheads/brapi-mcp-server/issues/99))

## Dependencies

- `vitest` ^5.0.4 → ^5.0.5.
