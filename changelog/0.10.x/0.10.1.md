# 0.10.1 — 2026-10-18

## Fixed

- **Markdown rendering** treats upstream names, IDs and advisory text as literals across formatters and trailers; structured values, staged rows and generated pedigree diagrams retain their semantics. ([#77](https://github.com/cyanheads/brapi-mcp-server/issues/77))
- **Inline row budgets** account for escaped rendered text as well as array JSON, preserving finder first-row exceptions and raw/SQL zero-row previews; omitted fetched rows remain retrievable from dataframes.
- **Client error contracts** declare reachable upstream 404/429 and finder-route failures with recovery guidance, preserving domain-specific translations and partial-success paths. ([#83](https://github.com/cyanheads/brapi-mcp-server/issues/83))
- **Genotype export coordinates** convert valid zero-based BrAPI starts to one-based VCF POS and PLINK positions; missing or invalid values retain their placeholders. ([#84](https://github.com/cyanheads/brapi-mcp-server/issues/84))
- **`brapi_find_variables`** unions distinct requested studies by variable ID under shared collection budgets, retaining row and staged-table provenance plus complete, partial, failed and unprocessed study coverage. ([#95](https://github.com/cyanheads/brapi-mcp-server/issues/95))
- **Identifier inputs** accept equivalent BrAPI `*DbId` / `*DbIds` spellings through aliases, including lone strings for array filters; conflicting spellings still fail. ([#97](https://github.com/cyanheads/brapi-mcp-server/issues/97))
- **Germplasm text scans** use configured first-page size independently of inline `loadLimit`, preserve served-size paging and report actual bounded coverage after an above-ceiling miss. ([#98](https://github.com/cyanheads/brapi-mcp-server/issues/98))

## Dependencies

- Added `marked` ^18.1.1 as a development dependency for parser-backed rendering tests.
