# 0.13.0 — 2026-11-27

## Changed

- **Breaking.** Germplasm-filtered genotype reads now require a working lookup from germplasm to call sets, including on upstreams that honor `germplasmDbIds` directly on `/search/calls`. ([#131](https://github.com/cyanheads/brapi-mcp-server/issues/131))
- **Study EDA.** `brapi_eda_study` and `brapi-guide` 1.2 explain how to recover variable IDs from the study record when variable scope is unavailable. The prompt reports coverage only when scoped counts support the calculation.
- **Framework and packaging.** Synced framework tooling and skills, enabled Bun for project scripts, and excluded Vitest caches from MCP bundles.

## Fixed

- **Genotype scope.** The finder and matrix export return `germplasm_scope_unavailable` when membership cannot be verified. The finder intersects resolved membership with explicit `callSetDbIds`. A verified empty scope returns an empty result, and over-returned calls are discarded with a warning.
- **Variable distributions.** `brapi_find_variables` counts ontology IDs and names separately, including nested SGN values, and counts scale data types. Warnings identify missing trait classes and scale names. ([#132](https://github.com/cyanheads/brapi-mcp-server/issues/132))
- **Variable study scope.** On the BrAPI Community Test Server, the finder rejects study-only filters and discloses dropped scope when another filter can run. Observation review reports membership as unverified, and `brapi_get_study` omits the unsupported variable count. ([#133](https://github.com/cyanheads/brapi-mcp-server/issues/133))
- **Scoped counts.** Verified study and germplasm mappings use one scoped count request. Unverified mappings still compare the scoped total with an unfiltered control. ([#134](https://github.com/cyanheads/brapi-mcp-server/issues/134))
- **Variable identity.** Rows without a usable `observationVariableDbId` are skipped with a count warning. Text ranks follow the matched row's position, and scan counts and valid study provenance survive skipped rows. ([#135](https://github.com/cyanheads/brapi-mcp-server/issues/135))
